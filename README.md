# 1Win template adapter

Локальный проект для копирования утверждённого шаблона `https://www.maniacba.com.ar/` и сборки трёх страниц из DOCX заказчика. Публикация на `1-win.co.tz` не выполняется. Результаты проверок и ограничения — в [REPORT.md](REPORT.md).

## Требования

- Node.js 22+
- npm
- `zip`
- Сетевой доступ к утверждённому домену для первого скачивания

## Входные файлы

Документы размещаются строго по путям:

```text
input/content/home/1Win Главная.docx
input/content/bet/1Win Bet.docx
input/content/casino/1Win Casino.docx
```

Все три DOCX уже получены из предоставленной папки Drive и сохранены локально. Встроенные изображения извлекаются из DOCX в `content/media/`. Файлы из папок `Pics` также сохранены в `input/content/<page>/Pics/` (5/4/4), но отдельное сопоставление этих файлов с местами в HTML не выполнялось: сайт использует изображения, встроенные в DOCX.

## Команды

```bash
npm ci
npm run scrape      # source/original: копия утверждённого хоста и manifest.json
npm run extract     # DOCX -> content/*.json и content/media/*
npm run clean       # рабочая копия и три оболочки в stage/
npm run populate    # контент, изображения, SEO, GOL5 и форматирование stage/
npm run format      # повторное форматирование читаемого stage/
npm run minify      # минимизация stage/ -> dist/
npm run prepare     # extract -> clean -> populate
npm run validate    # статические проверки
npm run build       # prepare -> minify -> validate -> package
npm run package     # обновить ZIP-архивы
npm run typecheck
npm run serve       # http://localhost:4173
npm run serve:stage # http://localhost:4173, просмотр stage/ с автообновлением
npx playwright install chromium
npm run browser-check  # 3 маршрута × 1440/768/390, скриншоты в qa/
```

После успешного `npm run scrape` выполняйте `npm run build`. В `stage/` остаётся читаемый HTML, CSS и JS; отдельная команда `npm run minify` создаёт компактный `dist/`. Если `stage/` или `dist/` уже заполнен, соответствующая команда запросит подтверждение перед перезаписью; в нетерминальном режиме она остановится. Для автоматической пересборки без запроса явно задайте `ALLOW_OVERWRITE=1 npm run build`. `npm run validate` проверяет готовый `dist/` после минимизации. Для просмотра `dist/` используйте `npm run serve`, для просмотра и редактирования `stage/` — `npm run serve:stage`. В последнем режиме изменения CSS применяются без перезагрузки страницы, изменения HTML и JS перезагружают её. Оба сервера используют порт 4173, поэтому запускайте только один из них. Для проверки на другом хосте задайте обе переменные `SOURCE_URL` и `SOURCE_HOST`; скрипт останавливается при редиректе за пределы утверждённого хоста.

Для дозагрузки значка из `meta[content]`, пропущенного первой версией парсера, повторите `npm run scrape` на машине с доступом к источнику и затем `npm run package`. Скрипт сохраняет уже скачанные файлы.

## Структура

```text
config/              домен, маршруты, DOM-якоря
scripts/             скачивание, извлечение, очистка, наполнение, проверка, упаковка
assets/adapter.css   адаптивные стили контента DOCX
input/content/       исходные DOCX
content/             извлечённые JSON и встроенные изображения
source/original/     нетронутая копия скачанного шаблона, отдельно от работы
work/                промежуточная копия
stage/               читаемые HTML/CSS/JS трёх страниц и локальные ресурсы
dist/                минимизированный готовый сайт
qa/                  скриншоты браузерной проверки, если она запускалась после сборки
deliverables/        ZIP-архивы после успешной сборки
```

`original-template.zip` содержит только `source/original/`. `finished-site.zip` содержит `stage/`, `dist/`, скрипты, конфигурацию, документы, извлечённый контент, скриншоты `qa/` (если проверка запускалась после последней сборки), README и REPORT. `node_modules` не архивируется.

## Проверка

Сборка, статические проверки и TypeScript-проверка прошли. Предыдущая браузерная проверка пользователем прошла на девяти комбинациях маршрутов и ширин, но относилась к версии до последнего изменения дизайна. Новую версию следует проверить командой `npm run browser-check`; она создаст скриншоты в `qa/`, после чего `npm run package` добавит их в архив. В песочнице агента запуск браузера ограничен; подробности и недостающий значок исходного шаблона перечислены в `REPORT.md`.
