# Отчёт о сборке

Дата: 21 ноября 2026 года. Готовый сайт собран локально. Пользователь ранее запустил браузерную проверку вне ограниченной песочницы; она прошла на трёх маршрутах и трёх ширинах экрана для версии до последнего изменения дизайна. Новая версия ожидает повторной браузерной проверки.

## Источник и скачивание

- Первоначальный адрес ТЗ `https://casino-1win-ar.com/` при веб-проверке переадресовывал на `https://www.maniacba.com.ar/`; поздний HEAD-запрос показывал также HTTP 301 на другой адрес. Пользователь явно утвердил `https://www.maniacba.com.ar/` как источник шаблона. Сторонние редиректы не скачивались как эквивалент.
- Фактический источник архива: `https://www.maniacba.com.ar/`. Главная вернула HTTP 200 и `text/html; charset=UTF-8`. Основной текст содержится в HTML, поэтому для сохранения страниц не требовался браузерный рендеринг.
- `robots.txt` доступен (HTTP 200), разрешает CSS/JS/изображения, запрещает `/wp-admin/`, `/cgi-bin` и feed, указывает `sitemap_index.xml`. Условия использования и права на отдельные изображения отдельно не подтверждались; пользователь разрешил использовать домен как шаблон.
- `npm run scrape`: **PASS**. В `source/original/` сохранены 83 URL без ошибок в манифесте: 4 HTML, 2 XML sitemap, 1 CSS, 1 JS, 10 шрифтов, 43 WebP, 9 AVIF, 6 JPEG, 3 PNG и 4 SVG. Также сохранены `robots.txt` и `manifest.json`. Исходные файлы после скачивания не редактировались.
- Сохранённые HTML: `/`, `/reglas/`, `/politica-de-privacidade/`, `/juego-responsable/`. Последние три страницы исключены из итогового сайта. `page-sitemap.xml` содержит ровно эти четыре URL; каждый найден в манифесте.
- В исходном HTML обнаружена одна ссылка на значок `/wp-content/uploads/2026/10/cropped-faviconV21-270x270.png`, отсутствующий в текущем архиве: первоначальная версия парсера не извлекала URL из `meta[content]`. Парсер исправлен, включая повторное сканирование сохранённого HTML; следующий `npm run scrape` в среде с доступом к источнику должен дозагрузить этот файл, сохранив уже скачанное. В итоговом HTML отсутствующий метатег удалён. До повторного скачивания исходный архив не является абсолютно полной копией всех ссылочных ресурсов.

## Итоговый сайт

- В читаемом `stage/` и минифицированном `dist/` ровно три HTML: `index.html`, `bet/index.html`, `casino/index.html`. `npm run clean` и `npm run populate` создают `stage/`; `npm run minify` отдельно создаёт `dist/`. Повторная запись в непустые каталоги требует подтверждения `yes` или `да` в терминале; для автоматизации доступен явный флаг `ALLOW_OVERWRITE=1`.
- `npm run serve` отдаёт `dist/`; `npm run serve:stage` отдаёт `stage/` и следит за его файлами. При изменении CSS браузер обновляет подключённый стиль, при изменении HTML и JS перезагружает страницу. Оба режима используют порт 4173.
- Все внутренние ссылки и локальные ресурсы в HTML используют относительные пути (`assets/...` на главной, `../assets/...` на вложенных страницах). Корневые `url(/...)` исходного CSS переписаны относительно его файла, включая десять ссылок на шрифты. Сборка проверяет разрешение путей при размещении в `/1win-test/` на GitHub Pages; canonical и sitemap сохраняют целевой домен `1-win.co.tz`.
- Исходные испанские блоки основного текста, футера, юридические утверждения, рекламные кнопки и закодированные внешние переходы удалены. Шапка и футер содержат только навигацию по трём целевым маршрутам. Встроенный исходный JS не переносится в итоговую версию; функция копирования `GOL5` реализована локально.
- Основные CSS, изображения и шрифты шаблона локализованы. Дополнительный `assets/adapter.css` использует цвета исходного шаблона (`#090e1a`, `#0d1428`, `#1d273f`, `#3d63f1`). Шапка сохраняет логотип слева и навигацию справа, включая мобильную ширину. Основные секции не имеют сплошных карточных фонов. На главной первый экран, `1Win Features`, бонусы и `1Win Site – Providers and Games` располагают растянутый по ширине текст сверху и изображение на всю ширину ниже. Единственная карточка промокода на каждой странице находится в нижнем правом углу изображения первого экрана. Остальные секции с изображениями сохраняют адаптивную боковую колонку. FAQ использует оригинальный SVG стрелки из сохранённого шаблона и нативные раскрывающиеся блоки с плавным открытием и закрытием; при настройке уменьшения анимации переход отключается. `assets/adapter.js` показывает уведомление после копирования `GOL5` либо сообщение о ручном копировании. Горизонтальный скроллбар таблиц имеет уменьшенную высоту.
- Для каждой страницы заданы `lang="en-TZ"`, собственные title/description/H1, canonical, `hreflang="en-TZ"` и Open Graph URL/title/description. `sitemap.xml` содержит ровно три адреса `https://1-win.co.tz/`, `/bet/`, `/casino/`; создан `robots.txt`.
- Внешних кликабельных ссылок, ссылок на исключённые маршруты, старого домена в HTML и кнопок с `data-href` статическая проверка не обнаружила. Код `GOL5` присутствует на каждой странице.

## Вопросы для согласования

- Документы содержат утверждения о лицензиях, бонусах, платежах и сроках выплат; их достоверность и обязательные предупреждения для Танзании не подтверждены технической проверкой. Тексты документов не переписывались.
- В предоставленных изображениях встречаются предложения «+500%» и «cashback up to 30%», тогда как текст DOCX описывает иные условия бонусов. Изображения оставлены без изменения как материалы заказчика; соответствие условий требует подтверждения заказчика.
- Исходный шаблон имел интерактивность, связанную с удалёнными внешними переходами и рекламой; эти элементы удалены из итоговой версии. В итоговом сайте остались локальная навигация и кнопка копирования кода.
